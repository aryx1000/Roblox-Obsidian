## How the UI kit works (2026-10-15)
- **Editable screens** live in `StarterGui` (each marked `KitScreen`); shared components in `ReplicatedStorage.MutantPetLab.UI.Components`; colours/timings code needs in `UI.Theme`; behaviour helpers in `UI.Kit`.
- **Code only fills data**: controllers clone in-screen templates (`*Template`, attribute `IsTemplate`) for repeating items.
- **Responsive**: `Kit.AttachScale` (0.8–1.25 by screen height); modals with `FitToScreen` shrink to fit short phones.
- **Navigation**: every screen exposes an `Open` BindableEvent; the HUD nav bar fires them. MobileUX only coordinates (one major screen at a time).
- **Sounds**: empty slots in `UI.Sounds` (Click, Open, Close, Place, Error, Pickup, Rotate) — assign SoundIds in Studio.
