# Reference Library

> [!important] Summary: [[MPL Visual Fingerprint]] · Master index: [[Master Visual and Gameplay References]]. Your living file: [[References for games with assets that I like and dont like.]] (analysis: [[Owner Reference Library]]). Avoid list: [[Do Not Copy]] · gaps: [[Reference Gaps]].


Visual and design references for MUTANT PET LAB. References communicate **principles** (mood, proportions, layout, interaction, materials, composition); they are not instructions to copy anything.

> [!important] Priority
> Approved [[Design Decisions]] > references (`status: active`) > inspiration. A written decision always beats an image.

## How to add a reference
1. **Quick capture:** drop the screenshot, link or idea into [[Reference Inbox]]. No organising needed.
2. **Make it a reference:** put the image in `References/Assets/`, create a note in the matching category folder from the `Reference` template (`Templates/Reference.md`), and embed the image with `![[file-name.png]]`.
3. Fill in *What I like*, *What I do NOT want copied* and *Apply this to MUTANT PET LAB*. Set `strength` to `reference` or `inspiration`, and `status` to `active` (or `needs-review` if unsure).
4. Claude can do steps 2–3 for you from the inbox when asked, then fills *Claude interpretation*.

Format example: [[Example - Reference Format]] (a demo note, hidden from the Base).

## How Claude interprets references
- Reads approved decisions first, then the relevant references **and their images** ([[Claude Workflow#Image and reference rules]]).
- **HARD REQUIREMENT** = an approved entry in [[Design Decisions]]. **REFERENCE** = qualities you like. **INSPIRATION** = brainstorming only.
- Records the extracted qualities in *Claude interpretation* so the image doesn't have to be re-read each time.
- Never copies characters, logos, exact colours or branded elements.
